# Lecture 4: NumPy and pandas

This unit connects native Python containers to NumPy arrays and pandas tables.
The scientific examples teach shape, axis meaning, dtype, vectorization,
broadcasting, labels, missingness, grouping, joining, and boundary validation.

## Notebook sequence

| Notebook | Topic | Approximate reference time |
| --- | --- | ---: |
| 00 | From Python containers to NumPy arrays and pandas tables | 135 minutes |

The notebook is a complete reference laboratory. A class meeting may cover its
core route together with another short unit or assign extensions separately.

## Learning outcomes

Students should be able to reason about arrays using shape, axes, dtype, views,
copies, vectorization, broadcasting, and reductions; use labeled pandas objects
without confusing label alignment with row position; state missing-data and join
policies; and expose validated numerical interfaces through reusable code.
