# Lecture 5: Visualization and Simulation

This unit treats a figure as a transformation that supports a stated question,
not as decoration. Its laboratory spans Matplotlib, seaborn, pandas plotting,
Plotly, accessible design, uncertainty, distributions, and deterministic
simulation examples.

## Notebook sequence

| Notebook | Topic | Approximate reference time |
| --- | --- | ---: |
| 00 | Scientific visualization and simulation | 165 minutes |

The instructor may select studios for live work and assign the remaining
examples as guided laboratory material.

## Learning outcomes

Students should be able to choose a plot from the analytical question, preserve
raw observations and uncertainty, diagnose misleading scales and encodings,
build accessible figures through explicit object interfaces, reproduce seeded
simulations, and export reviewable visual artifacts.

## Preparation

Complete Lecture 4 or be comfortable with NumPy arrays and tidy pandas tables.
