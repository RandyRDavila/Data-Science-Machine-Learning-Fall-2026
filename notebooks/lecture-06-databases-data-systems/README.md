# Lecture 6: Databases and Data Systems

This unit develops storage as part of the scientific system. It moves from
SQLite schemas and transactions to SQLAlchemy, DuckDB, Parquet, Arrow, Polars,
bounded access, and the roles commonly encountered in cloud workflows.

## Notebook sequence

| Notebook | Topic | Approximate reference time |
| --- | --- | ---: |
| 00 | Databases and data systems: local, remote, and larger than memory | 225 minutes |

This long-form notebook may span more than one live segment. The weekly
itinerary identifies the core database route and any assigned scale extensions.

## Learning outcomes

Students should be able to design constrained schemas, use parameterized SQL and
transactions, reason about missingness and join cardinality, distinguish local
and remote deployment from database semantics, estimate working-set size, and
select bounded analytical workflows before escalating infrastructure.

## Preparation

Be comfortable with Python functions, pandas tables, and the package and testing
boundaries established in Lectures 3 and 4.
