# Lecture 7: LLM Tools and Agents

This unit introduces hosted APIs, local and open-weight models, structured
output, tool calls, workflows, and agents. Probabilistic model behavior remains
inside deterministic validation, least-privilege authority, evaluation,
approval, idempotency, audit, and recovery boundaries.

## Notebook sequence

| Notebook | Topic | Approximate reference time |
| --- | --- | ---: |
| 00 | LLM tools and agents for scientific software | 225 minutes |

The core notebook and companion demonstrations run offline. Provider-specific
API calls are explanatory extensions and never require students to expose keys.

## Learning outcomes

Students should be able to distinguish a model, assistant, workflow, agent, and
tool; explain API request and credential boundaries; validate structured output;
design an allowlisted agent loop; keep documentation and training proposals
under ordinary software control; and evaluate model behavior without confusing
valid syntax with scientific truth.
