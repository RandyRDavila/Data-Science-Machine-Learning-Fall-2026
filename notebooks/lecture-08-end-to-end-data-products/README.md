# Lecture 8: End-to-End Data Products

This Part I synthesis traces one scientific value through durable storage,
domain policy, an HTTP API, a client, deployment, and operational evidence. The
notebook is a bounded local laboratory; package-backed components and companion
files represent the independently testable system boundaries.

## Notebook sequence

| Notebook | Topic | Approximate reference time |
| --- | --- | ---: |
| 00 | End-to-end data products: database to device | 225 minutes |

The instructor may divide the vertical slice across meetings or use selected
sections to synthesize earlier units. Completing every reference section live is
not required.

## Learning outcomes

Students should be able to define the endpoints of an end-to-end claim, trace a
value across database, service, API, network, and client boundaries, distinguish
build from deployment and release, select layered tests, and connect logs,
metrics, traces, and client evidence to user-visible outcomes.
