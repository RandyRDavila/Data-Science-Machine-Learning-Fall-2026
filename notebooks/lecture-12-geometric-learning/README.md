# Lecture 12: Geometric Learning

This unit studies methods whose behavior follows from a geometry: nearest
neighbors, margins, support vectors, and kernels. Scaling and representation are
therefore model decisions rather than generic cleanup.

## Planned notebook sequence

| Notebook | Topic | Professional artifact |
| --- | --- | --- |
| 00 | Nearest-neighbor classification and regression | Scaled kNN pipeline |
| 01 | Margins, support vectors, and kernels | Validated SVM pipeline |
| 02 | Dimension, latency, and invariance | Geometry and resource report |

Students compare validation behavior and prediction cost, then document where
the chosen metric or kernel encodes a scientifically defensible similarity.
