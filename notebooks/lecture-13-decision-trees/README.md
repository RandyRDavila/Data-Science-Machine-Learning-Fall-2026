# Lecture 13: Decision Trees

This unit develops recursive partitioning for regression and classification.
It treats depth, leaf size, pruning, instability, and interpretation as parts of
one statistical and software design.

## Planned notebook sequence

| Notebook | Topic | Professional artifact |
| --- | --- | --- |
| 00 | Recursive partitions and impurity | Tested tree baseline |
| 01 | Pruning, instability, and interpretation | Tree diagnostic report |

Students will read a fitted tree as a piecewise-constant function, not as a
causal explanation, and will test behavior at thresholds and missing-value
boundaries.
