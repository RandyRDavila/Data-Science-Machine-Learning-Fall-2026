# Lecture 14: Ensemble Learning

This unit gives ensemble methods the central treatment they deserve in modern
tabular machine learning. It contrasts variance reduction, randomized forests,
sequential error correction, and model combination.

## Planned notebook sequence

| Notebook | Topic | Professional artifact |
| --- | --- | --- |
| 00 | Bagging, random forests, and extra trees | Forest benchmark |
| 01 | AdaBoost and gradient boosting | Boosting benchmark |
| 02 | Voting, stacking, calibration, and selection | Champion-challenger report |

Out-of-fold predictions, resource budgets, feature-importance limitations, and
dependency choices are treated as first-class engineering concerns.
