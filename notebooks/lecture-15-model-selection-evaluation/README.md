# Lecture 15: Model Selection and Evaluation

This unit asks what evidence justifies choosing one candidate over another.
Cross-validation, nested evaluation, hyperparameter search, uncertainty, error
analysis, and promotion gates are organized around the deployment claim.

## Planned notebook sequence

| Notebook | Topic | Professional artifact |
| --- | --- | --- |
| 00 | Cross-validation as an estimator | Reusable split specification |
| 01 | Search, pipelines, and nested evaluation | Reproducible selection run |
| 02 | Error analysis, uncertainty, and promotion | Signed evaluation report |

Students must preserve an untouched estimate of final performance and account
for groups, time, repeated experimentation, and operational constraints.
